一个基于WebUSB的ADB工具，用于在浏览器中管理Android设备，支持应用安装等功能。

## 功能特性

### 1. 设备连接
- 有线USB连接（通过WebUSB）
- 设备状态显示
- 手动断开连接（释放 USB 接口，无需刷新页面）
- 连接/断开按钮互斥显示：未连接时显示"开始连接"，已连接时显示"断开连接"

### 2. 一键安装
- 应用管家
- 侧边栏
- 氢桌面
- 沙发管家
- 哨兵监控
- 小横条
- 易控车机PIP
- 红绿灯领航
- ADB Manager
- 虚拟返回键
- 一键清理
- 无障碍管理器
- 返回菜单键

### 3. 应用管理
- 选择APK文件
- 安装本地APK
- 查看已安装应用列表
- 启动/停止/卸载应用

### 4. 快捷启动
- 启动应用管家
- 启动侧边栏
- 启动氢桌面
- 启动沙发管家
- 启动布丁UI
- 启动 ADB Manager

### 5. 命令执行
- 手动执行ADB shell命令

### 6. 手机软件
- 蓝牙遥控（下载到手机）
- ADB 助手（下载到手机，运行时探测 Gitee 仓库最新版本）

## 使用说明

### 环境要求
- **浏览器**：Google Chrome 或 Microsoft Edge
- **设备**：Android设备
- **连接**：USB数据线

### 连接步骤
1. 使用Chrome或Edge浏览器访问工具页面
2. 点击"开始连接"按钮
3. 在设备上允许USB调试
4. 连接成功后即可使用各项功能

### 断开连接
1. 连接成功后，"开始连接"按钮会自动切换为"断开连接"
2. 点击"断开连接"并确认，工具会依次关闭 ADB 客户端、WebUSB 传输与 USB 设备，真正释放 USB 接口
3. 断开后按钮切回"开始连接"，再次点击即可重新连接，无需刷新页面

### 常见问题
1. **连接失败**：尝试拔插数据线，或运行 `adb kill-server`
2. **浏览器不支持**：使用Chrome或Edge浏览器
3. **权限问题**：确保设备已开启USB调试模式
4. **root权限**：部分系统工具需要root权限
5. **断开后无法重连**：点击"开始连接"会自动清理上一次的残留连接再重建；若提示接口被占用，请关闭其它 ADB 工具后重试

## 注意事项
1. 使用USB数据线连接设备
2. 首次连接需在设备上允许USB调试
3. 部分功能需要设备root权限
4. 使用过程中请保持设备连接稳定
